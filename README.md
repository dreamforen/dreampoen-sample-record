# 드림포이엔 시료채취기록 웹 v2

업로드된 실제 시료채취기록지 Excel 구조를 기준으로 만든 GitHub Pages용 정적 웹 앱입니다.

## v2 반영사항
- 원본 시료채취기록지 느낌의 표형 디자인으로 변경
- 기상 입력 순서: 기상 → 기온 → 습도 → 측정위치 대기압 → 대기압 → 풍향 → 풍속
- 풍향 선택형 입력
- 산소 3회 입력 + 산소 평균 자동계산
- 수분 5회 평균, 소수점 첫째자리 표시
- 1팀 / 2팀 장비 선택
  - 1팀 오리피스계수: 51 (고정)
  - 2팀 오리피스계수: 47.6 (고정)
  - 1팀 노즐: 0.317 / 0.472 / 0.609 / 0.759 / 0.957 cm
  - 2팀 노즐: 0.312 / 0.450 / 0.533 / 0.612 / 0.777 cm
- 노즐직경 버튼 선택
- 오리피스압차를 입력칸에서 제거하고 포인트별 자동계산
- K-factor를 입력칸에서 제거하고 자동계산
- 브라우저 임시저장 / 불러오기
- Excel 출력 / 인쇄

## GitHub Pages 업데이트
기존 저장소의 `index.html`, `style.css`, `app.js`, `README.md`를 이 버전으로 교체한 뒤 Commit 하면 기존 주소에 자동 반영됩니다.

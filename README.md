# 드림포이엔 시료채취기록 웹 v3

실제 시료채취기록지 Excel을 기준으로 제작한 GitHub Pages용 정적 웹 앱입니다.

## v3 반영사항
- 산소 3회 입력/평균 + 이산화탄소 3회 입력/평균
- 가스 조건 바로 아래 수분 5회 입력/평균 배치
- 원형 선택 시 가로/세로 값 삭제 및 입력 비활성화
- 사각형 선택 시 원형 내경 값 삭제 및 입력 비활성화
- 굴뚝·장비 조건에 측정점 계산/단면 도식 추가
  - 원형: 원형 단면 표시 + 원본 Excel의 직경 구간별 측정점 기준 계산
  - 사각형: 가로/세로 각각 4등분 값 자동계산 + 4×4 등분 도식
- 결과 표시 자릿수
  - 배출가스 밀도: 소수점 둘째자리
  - 평균 유속: 소수점 둘째자리
  - 굴뚝 단면적: 소수점 둘째자리
  - 표준상태 유량: 소수점 첫째자리
  - 등속흡인계수: 소수점 첫째자리
- 기존 1팀/2팀 장비 선택, 고정 오리피스계수, 노즐 선택, 오리피스압차/K-factor 자동계산 유지

## GitHub Pages 업데이트
기존 저장소에서 `Add file` → `Upload files`로 `index.html`, `style.css`, `app.js`, `README.md`를 덮어쓰기 업로드하고 `Commit changes`를 누르면 됩니다.

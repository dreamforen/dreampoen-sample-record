# 드림포이엔 시료채취기록지 웹 v4

기존 시료채취기록지 구조를 기준으로 만든 GitHub Pages용 정적 웹앱입니다.

## v4 반영사항
- 표준산소 입력 시 보정 전/후 유량 자동 표시
- 보정 전 농도 입력 시 표준산소 보정 후 농도 자동 표시
- 측정지점 표시를 표 형태로 변경
- 1팀 오리피스계수 51, 2팀 47.6 고정
- 전체 시료채취시간 입력란 추가
- 입자상 시료채취 시작시간 + 포인트별 채취시간 합계로 종료시간 자동계산
- 기타 항목(가스상) 측정조건 선택/추가 방식
- 적산유량계 채취 전 입력 → 채취 후 자동계산
- 누출검사 선택란 추가

GitHub Pages에는 index.html, style.css, app.js, README.md 네 파일을 업로드하면 됩니다.

# 드림포이엔 시료채취기록지 웹 v5

- 먼지 / 중금속 기록지를 완전히 독립 상태로 분리
- 24시간제 시간 입력(HH:MM)
- 원형 굴뚝: 단면적 기준 1/4/8/12/16/20점 자동 산정
- 원형 측정점 위치: 등단면적 반경식 적용, 관벽 2.5 cm 최소 이격 반영
- 사각형 굴뚝: 상등직경 계산, 면적·종횡비 기반 격자 자동 분할
- 계산된 측정점 수만큼 위치표 및 입자상 측정조건 입력행 자동 생성
- 표준산소 입력 시 보정 전/후 유량 자동 표시
- 보정 전/후 농도 입력란 제거
- 팀별 오리피스계수 및 노즐 선택, K-factor·오리피스압차 자동계산
- 적산유량계 전/후 및 누출검사
- 가스상 측정조건 항목 선택 추가

GitHub Pages에서는 index.html / style.css / app.js / README.md 4개 파일을 기존 저장소에 덮어쓰면 됩니다.


## v7 변경사항
- 원형/사각형 전체 법정 측정점과 대표 측정구 입력 지점을 분리
- 원형: 대표 측정구는 반경 구분수에 따라 1~5지점만 표시 (예: D=0.78 m → 0.276 m)
- 사각형: 전체 격자수는 내부 산정, 대표 측정구는 가로 방향 중심거리 1~5지점만 표시
- 담당자 서명 박스 제거, 이름 옆 `(인)` 표시
- 먼지 시료채취시간 입력란을 제목 바로 옆으로 정렬


## v10 변경사항
- 원형 대표 측정점 로직 유지
- 사각형 대표 측정구 위치를 격자 중심 좌표로 변경 (예: 0.80×0.80 m, 2×2 등분 → 1지점 0.200×0.200 m)
- 원형/사각형 측정점을 SVG 단면 그림에 자동 표시


## v10 사각형 측정점 보정
- 단면적별 최대 L(0.5 / 0.667 / 1.0 m) 적용
- 가로·세로 각각 ceil(길이/L)로 최소 분할 수 산정, 0.25 m² 초과 시 최소 4등분
- 전체 격자와 현장 대표 측정구의 실제 입력 지점을 분리
- 0.80 × 0.80 m 입력 시 2×2 등분, 대표 1지점 0.200 × 0.200 m
- 계산 결과를 사각형/원형 도식에 자동 표시


## v10 측정구 표시
- 원형/사각형 모두 오른쪽 측부를 측정구로 고정
- 단면 그림 오른쪽에 측정구와 프로브 삽입방향 자동 표시
- 사각형 측정점 그림은 오른쪽 측정구 기준으로 좌우 방향을 맞춰 표시
- 기존 계산값 및 원형/사각형 측정점 산정 로직은 유지


## v11 산출근거(로우데이터) 인쇄
- 기록지 뒤에 산출근거 페이지 추가
- 수분량, N2, 표준/실제 밀도, 유속, Vic, 노즐면적, 굴뚝면적, 오리피스압차, 등속흡입계수, Qa, 산소보정 Q 표시
- 각 항목의 기호, 계산식, 대입값, 산출값, 단위를 함께 출력
- 지점별 원시 측정값 표 추가
- 인쇄/PDF 시 산출근거 페이지는 새 페이지에서 자동 시작
- 먼지/중금속 전환 시 각각의 독립 입력값으로 재계산

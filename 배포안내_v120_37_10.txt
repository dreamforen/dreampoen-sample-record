DREAMFOREN v120.37.10 모바일 PDF 미리보기 수정
================================================

이번에 올릴 파일은 아래 6개뿐입니다.

웹 루트
1. index.html
2. style.css
3. v1203710.js

assets 폴더 안
4. assets/pdf.min.mjs
5. assets/pdf.worker.min.mjs
6. assets/pdfjs-LICENSE.txt

주의
- config.js는 업로드하거나 덮어쓰지 않습니다.
- app.js 및 기존 v120379.js도 변경하지 않습니다.
- SQL 실행은 필요하지 않습니다.

수정 내용
- 안드로이드·삼성 인터넷·모바일 Chrome/Whale에서 PDF iframe 대신
  PDF 페이지를 캔버스에 직접 표시합니다.
- PDF 이전/다음 페이지와 확대/화면 맞춤/축소 버튼을 제공합니다.
- 모바일 미리보기는 화면 전체를 사용하고 닫기 버튼을 상단에 유지합니다.
- PC의 기존 PDF iframe과 이미지·기타 파일 미리보기는 그대로 유지합니다.
- 직접 표시가 불가능한 PDF는 [새 창 열기]를 사용할 수 있도록 안내합니다.

배포 후
1. 위 6개 파일을 정확한 위치에 업로드합니다.
2. 모바일 브라우저 탭을 완전히 닫았다가 다시 엽니다.
3. 그래도 이전 화면이면 사이트 설정에서 캐시를 삭제한 뒤 접속합니다.
4. 화면 버전이 v120.37.10인지 확인하고 신고증명서 미리보기를 누릅니다.

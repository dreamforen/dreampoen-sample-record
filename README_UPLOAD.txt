2. 변경 내용
- 자료실은 목록에 필요한 정보부터 조회하고, 과거 기록의 전체 내용은 열기/다운로드/출력 시 가져옵니다.
- 시료채취기록, 분석 입력값, 작성 초안, 미전송 내용은 계정별 IndexedDB에 보관합니다.
- 기존 localStorage 자료는 첫 로그인 시 이전하고, 새 보관함에 실제 저장된 내용과 원본 백업을 확인한 후에만 기존 키를 제거합니다.
- PC와 모바일은 서버에 저장 확인된 원본을 함께 사용합니다. 초안과 미전송 내용은 해당 기기의 보관함에 남아 있습니다.
- 저장 버튼을 누르면 보낼 내용을 먼저 보관하고 서버 결과를 확인합니다. 연결이 돌아오면 미전송 자료의 전송을 다시 시도하며, 자료실에서 직접 다시 확인할 수도 있습니다.
- 분석 저장은 여지대장 조회 전에 입력값을 보관합니다. 여지대장 반영만 실패한 경우에도 미전송 상태를 유지하여 재시도합니다.
- 다른 직원/기기에서 변경된 서버 원본은 자동 덮어쓰기하지 않습니다. 서버에서 삭제된 자료도 자동으로 되살리지 않습니다.
- 기존 버전의 저장 확인 대기 기록은 미전송 목록으로 한 번 이전합니다. 이미 전송한 기록이 다시 대기 목록에 생기지 않도록 처리했습니다.
- 자료실에 '저장 상태 · 미전송 자료 · 초안 복구'를 추가했습니다. 기기 복구파일 다운로드/불러오기, 미전송 내용 확인/재시도, 초안 복구가 가능합니다.
- 기기에 쌓인 사본은 서버와 내용이 같은 것으로 확인된 자료만 최근 150건 중심으로 정리합니다. 열고 있는 기록, 변경된 초안, 미전송 내용은 제외하며 서버 원본은 삭제하지 않습니다.
- 관리자 전체 백업은 요약 목록이 아닌 서버 전체 원본을 조회하여 내려받습니다.

3. 적용 순서와 확인
1) 현재 작성 중인 내용은 저장 상태를 확인합니다. 서버 전체 백업이 필요하면 기존 자료실의 관리자 전체 백업을 먼저 내려받습니다.
2) 변경 파일 13개를 같은 배포에 포함합니다. 다른 파일은 교체하거나 삭제하지 않습니다.
3) 배포 완료 후 PC는 새로고침하고, 모바일은 페이지를 다시 엽니다. 화면의 Beta 3.8 표기를 확인합니다.
4) 각 PC/모바일 브라우저에서 평소 사용하는 회사 계정으로 로그인합니다. 기존 기기 자료 이전은 브라우저마다 별도로 실행됩니다.
5) 이전 과정에서 브라우저 데이터/사이트 저장공간을 삭제하지 마세요.
6) 자료실에서 과거 기록 열기와 엑셀 다운로드를 확인합니다. 새 기록을 저장한 뒤 '온라인 저장완료' 또는 '온라인 저장 확인 완료'를 확인하고, 다른 기기에서 새로고침하여 조회합니다.
7) 미전송이나 기기 보관 미확인이 표시되면 자료실의 저장 상태를 펼쳐 내용을 확인합니다. 창을 닫기 전에 기기 복구파일을 내려받을 수 있습니다.

4. 저장 상태의 의미
- 온라인 저장 확인 완료: 서버가 저장 결과를 반환했습니다.
- 기기에 보관됨 · 온라인 미전송: 해당 기기의 보관은 확인했으나 서버 전송은 완료되지 않았습니다. 다른 기기에는 아직 보이지 않을 수 있습니다.
- 저장/기기 보관 미확인: 브라우저 보관 또는 서버 저장을 확인하지 못했습니다. 복구파일을 다운로드하고 실패 내용을 확인해야 합니다.
- 서버 변경 충돌: 미전송 내용을 보존합니다. 최신 원본과 비교 후 저장해주세요.
- 분석 원본은 저장됐지만 여지대장 반영 실패: 미전송 목록에서 다시 확인하면 분석 원본의 중복 저장 없이 여지대장 반영을 재시도합니다.

5. 보관 범위와 운영상 한계
이번 전환 대상은 용량 오류를 일으킨 시료채취·분석 기록의 저장/조회 경로입니다. 계약·품질문서 등 다른 업무의 서버 구조는 변경하지 않았습니다.
IndexedDB도 브라우저와 기기의 저장공간 한도가 있습니다. 브라우저 데이터 삭제, 기기 고장 등으로 서버에 보내지 못한 기기 자료가 사라질 가능성은 남아 있으므로, 미전송 상태를 방치하지 말고 복구파일을 활용해주세요.
이 패키지는 서버 제공업체의 요금제·자동 백업·복구 정책을 설정하지 않습니다. 회사의 장기 보관을 위한 서버 용량 관리와 정기 백업은 별도로 운영해야 합니다.
이전 버전은 새 IndexedDB 보관함을 읽지 못합니다. 버전을 되돌리기 전에는 온라인 전송 상태를 확인하고 기기 복구파일을 내려받아 보관해주세요.

DREAMFOREN v120.37.9 FULL 배포 안내
====================================

1. 배포 파일
- dreampoen_sample_web_v120_37_9_FULL.zip
- 압축을 풀어 기존 웹 폴더에 전체 파일을 업로드합니다.
- 기존 config.js는 변경하지 말고 그대로 유지합니다.

2. 이번 안정화 내용
- Chrome/Whale 및 모바일에서 팝업이 차단되어 미리보기·인쇄가 열리지 않을 때
  현재 화면 안의 안전 미리보기로 자동 전환합니다.
- 견적서, 거래명세서, ERP 인쇄, 품질문서, 결재·게시판 첨부파일 등
  기존 window.open 기반 화면을 공통으로 보호합니다.
- 모바일 팝업이 화면 밖으로 밀리거나 닫기 버튼이 가려지는 현상을 보완했습니다.
- 누락되어 있던 2026년 측정일 원본 자료를 정상 복원했습니다.
  (원본 918건 / 업체·주소 그룹 291개 / 상반기 732건 / 하반기 186건)
- 누락되어 로그인·분석 화면에서 엑박이 나던 기존 로고 원본을 복원했습니다.
- 더 이상 사용하지 않으면서 누락 오류를 만들던 template_data.js 연결만 제거했습니다.
  현재 측정기록 Excel 출력은 기존 dreampoen_record_template.xlsm을 그대로 사용합니다.

3. 보존 확인
- 계약일 기준 상태·계약/업체 직접연결·업체현황 반영 기능 유지
- ERP 직원 권한·비고 저장·목록 전화번호 읽기 전용·정렬 기능 유지
- 견적 관리 [수정][미리보기][인쇄] 한 줄 배치 유지
- 승인된 견적서 A4 디자인, 로고 제거, 인감 이중경로, 공급가액 위 선 제거 유지
- config.js 원본과 SHA-256 값이 동일하며 코드 변경 없음

4. SQL
- 추가 SQL 실행은 필요하지 않습니다.

5. 배포 후 확인
- 브라우저에서 Ctrl+Shift+R로 강력 새로고침합니다.
- 좌측 버전 표시와 하단 System 표시가 v120.37.9인지 확인합니다.
- PC와 모바일에서 견적 미리보기 및 품질문서/첨부파일 미리보기를 각각 한 번 확인합니다.
- 팝업이 허용된 브라우저는 기존 새 창을 그대로 사용하며,
  차단된 브라우저만 현재 화면의 대체 미리보기를 사용합니다.

6. 참고
- 계정 로그인 이후의 실제 권한별 전체 메뉴는 배포 환경 계정으로 최종 확인해야 합니다.
- 남는 문제가 있으면 관리자 화면의 오류진단에서 로그 복사를 눌러 전달하면
  화면·기능 위치를 정확히 추적할 수 있습니다.

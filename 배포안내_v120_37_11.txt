DREAMFOREN v120.37.11 기상 연동 복원
=====================================

업로드 방법
1. DREAMFOREN_v120_37_11_UPLOAD.zip의 압축을 풉니다.
2. 압축 안의 파일과 폴더를 현재 GitHub 웹 저장소 루트에 모두 업로드합니다.
3. config.js는 ZIP에서 의도적으로 제외했습니다. 서버의 기존 config.js를 그대로 유지합니다.
4. SQL 실행은 필요하지 않습니다.

이번 수정 내용
- 현재 v120.37.10의 계약·업체현황·ERP·견적서·모바일 PDF 기능을 그대로 유지합니다.
- v120.46~v120.47에서 정상 작동했던 기상 연동만 선별 복원했습니다.
- 업체현황 주소를 시/도·시/군/구·읍/면/동으로 자동 판별합니다.
- 측정일과 전체 채취 시작시간을 기준으로 기상청 3시간 발표회차를 조회합니다.
- 기상·기온·습도·풍향·풍속을 자동 입력합니다.
- 측정위치대기압과 대기압은 현장 수기값이므로 자동으로 덮어쓰지 않습니다.
- 풍향은 웹 선택값과 일치하는 16방위 표기를 사용하며 풍속 0은 무풍으로 입력합니다.

배포 후 확인
1. 화면 왼쪽/하단 버전이 v120.37.11인지 확인합니다.
2. 시료채취기록지에서 업체를 선택합니다.
3. 측정일과 전체 채취 시작시간을 입력합니다.
4. 기상데이터 가져오기를 누릅니다.
5. 기상·기온·습도·풍향·풍속이 입력되는지 확인합니다.
6. 업체현황, ERP 비고 저장, 견적서 미리보기·인쇄, 모바일 PDF 미리보기도 확인합니다.

기상 조회 오류가 발생하는 경우
- 기존 Supabase Edge Function인 dreamforen-location과 dreamforen-weather가 배포되어 있어야 합니다.
- 오류 문구를 그대로 캡처하면 함수 설정 문제인지 데이터 문제인지 구분할 수 있습니다.

검증 결과
- 정상 기상본의 연동 코드와 일치 확인
- 계약 상태·업체현황 연결 검사 통과
- ERP 전화번호·비고 관련 기존 파일 무변경 확인
- 견적서 수정·미리보기·인쇄 및 승인 디자인 검사 통과
- 모바일 PDF와 PC 팝업 대체 미리보기 검사 통과
- config.js 원본과 동일함 확인 및 업로드 ZIP에서 제외

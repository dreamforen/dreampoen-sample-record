[3] Supabase에서 1회 실행할 SQL
- 25_v12031_quality_edit_permission.sql

이 SQL은 기존 품질문서와 개정이력을 삭제하지 않습니다.
직원관리의 "품질문서 수정·업로드"가 체크된 직원에게만 품질문서 저장 권한을 부여합니다.
관리자는 항상 수정할 수 있고, 일반 직원의 기본값은 열람 전용입니다.

[4] 배포 확인 순서
1. 위 GitHub 파일을 정확히 같은 경로에 업로드합니다.
2. GitHub Pages 반영을 기다립니다.
3. 브라우저에서 Ctrl + F5를 누릅니다.
4. 왼쪽 메뉴 또는 하단에서 v120.31.0을 확인합니다.
5. 관리자 계정으로 직원관리에서 필요한 직원만 "품질문서 수정·업로드"를 체크하고 저장합니다.

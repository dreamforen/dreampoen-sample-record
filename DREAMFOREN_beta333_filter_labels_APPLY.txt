DREAMFOREN Beta 3.33 — 성적서작성 > 4. 여과지라벨

적용 순서
1. ZIP 압축을 해제합니다.
2. 아래 웹 파일 7개를 GitHub 저장소 dreamforen/dreampoen-sample-record의
   기존 index.html과 같은 최상위 위치에 업로드합니다.
   - index.html
   - navigation_guard.js
   - menu_permissions.js
   - filter_label_model.js
   - filter_labels.js
   - filter_labels.css
   - filter_label_logo.jpg
3. GitHub Pages 배포 완료 후 웹에서 Ctrl+Shift+R을 누릅니다.
Supabase SQL 적용이나 서버 폴더 업로드는 필요 없습니다.
ZIP과 이 안내문은 GitHub에 업로드하지 않아도 됩니다.

사용 방법
1. 성적서작성 > 4. 여과지라벨에 들어갑니다.
2. 측정일 시작과 끝을 정하고 ‘조회’를 누릅니다. 기본 기간은 이번 달 1일~오늘입니다.
3. 업체·접수번호·시설·여지번호로 검색하거나 팀을 고릅니다.
   웹 성적서의 발급 상태가 등록되어 있다면 ‘발급완료만’으로도 찾을 수 있습니다.
   한글에서 별도로 완성한 성적서처럼 웹 발급 상태가 없으면 ‘전체 대상’에서 직접 고릅니다.
4. 보낼 기록을 선택합니다. 업체명·접수번호·시설명·인쇄 수량은 이번 인쇄용으로 수정할 수 있습니다.
   ‘검색결과 전체 선택’은 현재 검색 조건의 모든 페이지를 선택합니다.
   조건을 바꿔도 이미 선택한 건은 유지하므로 선택 건수와 미리보기를 확인해주세요.
5. ‘라벨 미리보기 / 인쇄’를 누릅니다. 팝업을 차단한 브라우저는 이 사이트의 팝업을 허용해주세요.
6. 새 창에서 ‘인쇄 / PDF 저장’을 누릅니다.
   인쇄 설정: A4 / 세로 / 배율 100% / 여백 없음 / 머리글·바닥글 끄기.
   프린터별 실제 출력은 먼저 한 장 출력해 자로 크기를 확인해주세요.

자동 작성 기준
- 시료채취기록에 여지번호가 있는 먼지 또는 먼지+중금속 기록을 표시합니다.
- 여지번호 없음, 중금속 전용, 숨김·삭제·영구 삭제한 기록은 제외합니다.
- 업체명·접수번호·측정시설을 자동으로 넣습니다. 여지번호는 목록에서 확인용으로 표시합니다.
- 동일한 업체 ID가 확인되면 현재 업체명을 사용하고, 연결을 확인할 수 없으면 저장 당시 이름을 유지합니다.
- 시설명은 측정 당시 기록을 사용하며, 시설번호와 용량이 있으면 원본처럼 줄을 나눕니다.
- 서버와 기록지의 접수번호나 측정종류가 다른 건은 자동 인쇄에서 제외하고 ‘원본 확인 필요’에 표시합니다.
- 웹 성적서 발급 상태 조회에 실패하면 완료로 판단하지 않고 ‘확인 불가’로 표시합니다.

인쇄 양식
- 사용자 제공 여과지.hwp의 업체명 / 접수번호 / 측정시설 / 보존기간 / 회사 로고 구성을 사용합니다.
- 보존기간 문구와 회사 로고는 원본을 유지합니다.
- 라벨 한 개는 가로 55mm × 세로 70mm입니다.
- A4 세로에 3열 × 4행, 12개씩 배치합니다.
- 13개부터 다음 장으로 넘어가며 남는 칸에는 빈 양식을 표시합니다.
- 긴 글자는 공간에 맞춰 조정합니다. 조정 후에도 넘치면 인쇄 버튼을 막고 내용 수정을 안내합니다.

자료 및 권한
- 시료채취기록과 성적서는 읽기만 하며 원본을 저장·수정·삭제하지 않습니다.
- 라벨에서 수정한 내용은 이번 인쇄용이고 페이지 새로고침이나 자료 재조회 시 초기화됩니다.
- 시료인수인계대장, 먼지여지대장, 분석 및 성적서의 기존 저장·연동 로직을 변경하지 않았습니다.
- 기존 ‘성적서 작성’ 조회 권한을 그대로 사용하며 직원의 기존 권한을 변경하지 않습니다.

검증 및 적용 상태
먼지 대상 구분, 회사명 변경, 12개/13개 인쇄, 긴 글자, 권한 제한 및 원본 보존을 로컬에서 확인했습니다.
실제 운영 DB 접속이나 GitHub 배포는 수행하지 않았습니다. 파일 적용 후 실제 자료로 확인해주세요.

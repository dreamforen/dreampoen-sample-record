DREAMFOREN v120.30.0 배포 안내
================================

1. GitHub에 업로드·교체할 파일
--------------------------------
- index.html
- app.js
- style.css
- approval.js
- qms.js
- qms_sections.js
- leave.js
- v12030.js  (신규 파일, 반드시 업로드)

2. Supabase SQL Editor에서 실행할 파일
--------------------------------------
- 24_v12030_approval_admin_delete.sql  (신규, 1회 실행)

실행 순서:
22_v12028_internal_approval.sql → 23_v12029_quality_sections_leave.sql → 24_v12030_approval_admin_delete.sql
앞의 22·23번을 이미 실행했다면 24번만 실행합니다.

3. 유지할 파일
--------------
- config.js는 현재 GitHub 파일을 그대로 유지합니다. 교체하거나 삭제하지 않습니다.
- assets/quality_manual_rev02.pdf는 그대로 유지합니다.
- assets/quality_manual_rev02.hwp도 그대로 유지합니다.

4. 적용 확인
------------
- GitHub 업로드 완료 후 2~5분 기다립니다.
- Ctrl + F5를 누릅니다.
- 왼쪽 메뉴 하단 또는 홈페이지 하단에서 v120.30.0을 확인합니다.

5. 확인할 기능
--------------
- 내부결재 새 기안 및 연차 팝업 좌우 여백
- 연차 날짜에 20240616 입력 → 2024-06-16 표시
- 관리자 계정에서 승인·반려·테스트 결재문서 삭제
- 승인 연차 삭제 시 일정 제거 및 사용 연차 복원
- 품질매뉴얼 원본 모드의 Rev.00~Rev.03 개정이력
- 품질문서 결재상신 취소 후 품질문서 화면 유지
- 원통여지관리대장 미리보기와 인쇄 각각 실행

주의
----
원본 PDF는 기준자료로 보존됩니다. 장별 개정 승인 내용은 DB의 승인 개정본으로 관리되며,
현재 버전에서는 기존 PDF 파일의 글자와 표를 직접 바꾸어 새 PDF로 자동 생성하지 않습니다.
